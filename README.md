# Open Library: Book Discovery and Subject Analytics Pipeline

An end-to-end data engineering project that collects book and author data from public APIs, transforms raw responses into structured relational tables, and prepares analytics-ready data for book discovery and subject analysis.

## Project Overview

This project demonstrates a local ETL pipeline that processes Open Library data through three layers:

- **Bronze Layer:** Stores raw API responses for further processing.
- **Silver Layer:** Transforms and organizes data into relational MySQL tables.
- **Gold Layer:** Prepares structured data for analytics on subjects, authors, and publications.

## Key Features

- Ingests book and author data from public APIs.
- Organizes data into Bronze, Silver, and Gold layers.
- Uses MySQL to store structured relational data.
- Supports data quality checks and validation.
- Maintains ingestion and processing information for pipeline tracking.
- Enables SQL-based analysis of books, authors, and subjects.

## Technologies Used

- Python
- MySQL
- REST APIs
- SQL
- YAML for configuration

## Pipeline Workflow

1. Fetch data from the Open Library API.
2. Store raw API responses in the Bronze layer.
3. Transform and normalize data into relational tables in the Silver layer.
4. Validate the processed data.
5. Prepare Gold-layer data for analytical queries.

## Use Cases

- Exploring books by subject.
- Analyzing authors and their associated works.
- Investigating publication trends.
- Practicing API ingestion, data transformation, relational database design, and SQL analytics.
